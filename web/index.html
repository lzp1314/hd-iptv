运行设置

保存后立刻生效，不用重启容器。上游按出口 IP 限频，别把「自动更新间隔」调太勤， 也别对着一堆台连点重试。「播放方式」平时用直连（分片由播放器自己去 CDN 取，最流畅）， 播放器报跨域或 403 时再换成经本机转发。

套了反向代理（Lucky / Nginx）时「对外地址」留空即可，面板和订阅列表都会用你访问时的域名和端口。 改完在下一次更新时生效，想立刻看效果就点一次「立即更新」。 「自动按省取源」「省份 / 运营商」不在这里，挪到了左侧「宽带与省份」那一页。

宽带与省份

这一页只管一件事：告诉程序你这条宽带是哪省哪家，好去取本省的运营商单播清单——只给已有的央视 / 卫视补线路， 不会凭空多出台。用「自动识别」就能跑，识别不准、或者你知道自己走的是哪家出口时，再手动指定。

检测和扫描都不改配置，只是查给你看；挑到有源再点右上角「保存」。 湖北移动、广电会被程序自动跳过（前者已内置运营商源，后者没有公开单播清单）。 选的省份或运营商跟你实际出口对不上时，探测会大面积超时或报错——那是运营商源按省隔离的正常表现，不是装坏了。

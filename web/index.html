运行设置

保存后立刻生效，不用重启容器。播放地址是播放时现换的，列表多久更新一次 都不影响能不能放；「清单缓存」是播放器每次取清单时多久真的去上游要一次， 嫌卡就调大。上游按 IP 限频，别把「自动更新间隔」调太勤，也别对着一堆台连点重试。

套了反向代理（Lucky / Nginx）时，「对外地址」留空即可，列表会用你访问面板的外网域名和端口。

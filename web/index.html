运行设置

保存后立刻生效，不用重启容器。上游按出口 IP 限频，别把「自动更新间隔」调太勤， 也别对着一堆台连点重试。「播放方式」平时用直连（分片由播放器自己去 CDN 取，最流畅）， 播放器报跨域或 403 时再换成经本机转发。

套了反向代理（Lucky / Nginx）时「对外地址」留空即可，面板和订阅列表都会用你访问时的域名和端口。 改完在下一次更新时生效，想立刻看效果就点一次「立即更新源」。 「自动按省取源」「省份 / 运营商」不在这里，挪到了左侧「宽带与省份」那一页。

源数据与订阅地址 模块开关

点开一个模块看说明、改配置，用模块名右边的开关决定它参不参与。关掉的模块不再采集， 订阅里也立刻消失，不用等下一轮更新。想让订阅里只有咪咕，就只打开「咪咕视频」。

更多源 （sources.toml 里的其它条目，各自独立开关）

模块把 sources.toml 里相关的源归到一组管理：官方直连已并入「运营商官方源」， 聚合源三条并入「第三方聚合源」，央视频的两条接口并入「央视频」。 「少儿频道」是独立采集源，开启后自己抓 CCTV-14、咪咕少儿和聚合列表里的少儿台， 不依赖其它模块的开关。所有启用的模块都在右侧同一条 M3U 订阅里，开几个就有几个分组。

模块配置

网络地址族

决定这个模块取流时走 IPv4、IPv6 还是自动。改完立即保存，播放时生效。

央视频 · 播放兼容

只影响央视频下发出去的播放地址，其它模块不受影响。改完立即生效，不用重建容器。

咪咕视频 · 账号与画质

央视 / 卫视等公开频道播放时现换一张有效地址，由播放器按自己网络就近取流。

账号令牌只存本机，不进播放地址、订阅链接或日志。令牌失效时平台不会报错， 只会按游客给流，播放不中断，日志会提示重新获取。

宽带与省份

这一页只管一件事：告诉程序你这条宽带是哪省哪家，好去取本省的运营商单播清单——只给已有的央视 / 卫视补线路， 不会凭空多出台。用「自动识别」就能跑，识别不准、或者你知道自己走的是哪家出口时，再手动指定。

自动换源：一个台挂着好几条线路时，播放中某条被上游拒、或者清单不再往前推进， 就自动换到下一条。开着更抗封（一条挂了还有替补）；关掉则固定用第一条，取不到就如实报错。 线路之间来回跳、画面一卡一卡的时候，先把它关掉——通常是某条线路本身坏了，关掉能立刻稳下来， 也方便你看清到底是哪条在坏。关掉不影响「同一个地址重试」，只是不再换到别的地址。

检测和扫描都不改配置，只是查给你看；挑到有源再点右上角「保存」。 湖北移动、广电会被程序自动跳过（前者已内置运营商源，后者没有公开单播清单）。 选的省份或运营商跟你实际出口对不上时，探测会大面积超时或报错——那是运营商源按省隔离的正常表现，不是装坏了。
